# realtorial

### Team names and abstract
- Team Lead/Machine Learning SME/Floater: Matt Heeter
- Augmented Reality SME/QA/Floater: Cael Thompson
- Advisor: Giovani Abuaitah

Realtorial is an augmented reality platform for creating and following tutorials. Realtorial guides users through tasks via a head mounted display, providing guidance to users via an overlay that highlights the object(s) needed for a task and provides cues for what to do with the objects(s). It enables people to know the objects and tools they need without prior knowledge of what they look like.
