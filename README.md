# realtorial

### Team names and abstract
- Team Lead/Machine Learning SME/Floater: Matt Heeter
- Augmented Reality SME/QA/Floater: Cael Thompson
- Advisor: Giovani Abuaitah

Realtorial is an augmented reality (AR)-based platform for creating and following tutorials. Realtorial will guide users through tasks via a head mounted display (HMD), providing guidance to users via an AR overlay that finds and highlights the object(s) needed for the task and provides cues for what to do with the objects(s). From the tutorial creation side, users will “record” themselves performing actions, making note to call out necessary objects and their manipulations. From there, tutorial-specific machine learning (ML) computer vision (CV) models will be trained. For tutorial followers, Realtorial will use the models from the creators to segment the same objects within their space. Object manipulations specified by the creators will also be shown, allowing tutorial followers to be guided through the task in their own, likely different, physical spaces.
